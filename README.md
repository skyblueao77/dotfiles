# dotfiles

## Environment

WSL2 Ubuntu development environment.

## Managed configuration

- Fish
- Git
- SSH
- Starship

## Base tools

- Git / Git LFS
- ripgrep
- fd
- fzf
- eza
- bat
- zoxide
- jq

## Runtimes

- uv / Python
- Node.js / npm
- Julia / Juliaup

## Bootstrap

1. Install WSL / Ubuntu
2. Configure SSH
3. Clone this repository
4. Run packages.sh
5. Run setup-links.sh
6. Install runtimes

## Security

Private SSH keys and credentials are never stored in this repository.
